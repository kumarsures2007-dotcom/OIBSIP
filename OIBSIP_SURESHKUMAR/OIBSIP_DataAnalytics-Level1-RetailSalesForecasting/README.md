# 📖 Project Overview

This project develops a machine learning model to analyze historical retail sales data and forecast future sales. The workflow includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and sales prediction.

The objective is to help businesses understand sales patterns and improve decision-making through predictive analytics.

---

# 🎯 Objectives

- Load and inspect the retail sales dataset
- Clean and preprocess the data
- Perform Exploratory Data Analysis (EDA)
- Analyze sales trends and customer behavior
- Engineer useful features for prediction
- Train a machine learning regression model
- Evaluate model performance
- Forecast future retail sales

---

# 📂 Dataset

**Dataset:** retail_sales_dataset(1).csv

The dataset contains retail transaction information such as sales date, products, quantity sold, customer details, and sales amount. These features are used to analyze historical trends and build a forecasting model.
