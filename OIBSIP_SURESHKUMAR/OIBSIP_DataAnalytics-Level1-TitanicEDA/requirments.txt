# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

## 📌 Project Information

**Project:** Exploratory Data Analysis (EDA) on Titanic Dataset

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand passenger demographics, survival patterns, and the factors that influenced survival.

---

# 🎯 Objectives

- Load and inspect the dataset
- Clean missing values
- Perform descriptive statistical analysis
- Analyze passenger demographics
- Explore survival patterns
- Visualize important relationships
- Generate meaningful business/data insights

---

# 📂 Dataset Information

**Dataset:** Titanic Dataset

### Features

| Column | Description |
|---------|-------------|
| PassengerId | Passenger ID |
| Survived | Survival Status (0 = No, 1 = Yes) |
| Pclass | Passenger Class |
| Name | Passenger Name |
| Sex | Gender |
| Age | Age |
| SibSp | Number of Siblings/Spouses |
| Parch | Number of Parents/Children |
| Ticket | Ticket Number |
| Fare | Ticket Fare |
| Embarked | Port of Embarkation |

# 💡 Key Insights

- Female passengers had a higher survival rate than male passengers.
- First-class passengers were more likely to survive than second- and third-class passengers.
- Most passengers traveled in third class.
- Younger passengers had slightly better survival rates.
- Ticket fare showed a positive relationship with survival, as higher-paying passengers generally had better survival chances.
